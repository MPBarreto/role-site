# Payment method logos

- Pix icon: Simple Icons SVG (`https://cdn.simpleicons.org/pix`), distributed under CC0 by the Simple Icons project (`https://github.com/simple-icons/simple-icons`). The SVG is kept as the source file; the WebP file is a raster export used by the app.
- Apple Pay: Apple Pay mark downloaded from Apple's official marketing assets (`https://developer.apple.com/apple-pay/marketing/`). The SVG is kept as the source file; the WebP file is a raster export used by the app.
- Google Pay: official logo from Google's developer brand guidelines (`https://developers.google.com/pay/india/api/web/brand-guidelines`, asset: `https://developers.google.com/static/pay/api/images/brand-guidelines/google-pay-logo.png`). The original source PNG is kept as downloaded; the app uses an optimized WebP export.

The logos are shown only as identifiers for payment methods and are not recolored or redrawn.
